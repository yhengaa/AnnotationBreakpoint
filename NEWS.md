# AnnotationBreakpoint 0.3.0

- Preserves `proxy_prefix` as the default fixed-ranking search and exact
  enumeration as the small-domain alternative.
- Accepts an optional strictly increasing positive prefix schedule through the
  R API or `--prefix-sizes`, while preserving the fixed default, single frozen
  ranking, exact-prefix rejection, and replay semantics.
- Adds an explicit compatible-runtime policy for patch-level R or edgeR
  differences while retaining exact-version reproduction as the default.
- Records expected and observed runtime versions and propagates structured
  original-fit failure reasons, backend errors, and warnings to reports and
  console output.
- Restores self-contained fixture tests for validation, exact results,
  pseudobulk conservation, constraints, replay, mutation detection, and report
  rendering.
- Adds per-function help, a buildable vignette, focused continuous integration,
  and package citation metadata.
- Adds sparse `counts.rds` input, JSON-encoded named sample/donor caps, and a
  standalone raw-COMBAT reconstruction utility with frozen selection metadata.
- Narrows the installed package to the supported analysis, search, replay, and
  reporting components. Historical evaluation evidence remains unchanged in
  the source repository.

# AnnotationBreakpoint 0.2.0

- Established observed-centered proxy-ranked cumulative prefixes as the
  practical default.
- Added saved replay-verified FAM118A and PDXK examples and the indexed compact
  evidence archive.

  search-method contribution claim.
